A one-image front page summing up the world news of Wednesday 25 November 2026: the drone strike on the cargo ship Sparta II, naval mines hitting oil tankers in the Strait of Hormuz, Nvidia and the Nikkei falling on AI doubts, and the brighter notes of Shenzhou-24 carrying Pakistan's first astronaut and Senegal regaining the Africa Cup of Nations title.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program validates the bundled `entry.png` (PNG magic bytes, at most
1 MiB, at most 1024×1024) and writes the exact bytes to
`out/entry.png`. It needs no network and no dependencies — Node 22
standard library only — and both runs write byte-identical output.
